## Objective

Add a single-action export of the currently active tree as a PNG image. Two modes: **transparent** (no background, no overlays) and **themed background** (current canvas bg color). Standalone feature — no coupling with v1.8 or v1.10. One new dependency (`html-to-image`).

## Resolved Spec Decisions

| # | Question | Decision |
|---|---|---|
| 1 | **Format** | PNG only at 2× pixel ratio. SVG explicitly out of scope per refined inventory. |
| 2 | **Library** | `html-to-image` (~14 KB gz, no peer deps, handles SVG-heavy DOM). Picked over `dom-to-image` (less maintained) and `canvas2html` (different API). |
| 3 | **Capture target** | The React Flow root element via `ref`. Pass to `toPng` with explicit `width`/`height`/`style.transform` derived from `getNodesBounds()` so the image contains the full tree, not just the visible viewport. |
| 4 | **Overlay handling** | Set a transient `exportInProgress: 'transparent' \| 'themed' \| null` flag on the store; `Canvas.tsx` and `BTNode.tsx` read it and conditionally hide `AxisOverlay`, `OriginCross`, the selection ring, and (transparent mode) `<Background>`. RAF wait between flag-set and capture so React commits the unmounts. |
| 5 | **Transient flag in undo?** | No. The flag is pure UI state, not in the unified timeline. |
| 6 | **Filename UX** | Default `<treeName>.png`; auto-append `.png` if missing (matches v1.1 file rename precedent). Browser default for collision handling (no overwrite warning needed in v1.9). |
| 7 | **Failure UX** | If `toPng` throws, modal stays open with inline error `Export failed: <message>`; flag clears via `try/finally`. |

## Out of Scope

- SVG export.
- Batch export of all tabs.
- Custom resolution / DPI selection.
- Title/legend/footer/watermark inclusion.
- Server-side rendering of the export.
