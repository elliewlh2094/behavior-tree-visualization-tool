# Todo: Behavior Tree Visualization Tool — v1.11 "Web Presence & Discoverability"

## Objective

Make the tool openable in a browser at a public URL with a polished landing page, and add four in-editor usability wins. Two phases:

- **Phase A — Web Distribution:** FR3 (landing + HashRouter) + FR5 (GitHub Pages deploy). Phase A0 (asset-path + base) lands first because a subpath `base` silently breaks every absolute `/asset` path.
- **Phase B — In-Editor Usability:** FR6 (search), FR7 (minimap), FR8 (templates), FR9 (unsaved guard). FR9 is independent; FR8 depends on Phase A's router/landing.

## Resolved Spec Decisions

| # | Question | Decision |
|---|---|---|
| 1 | **Landing vs editor wiring** | `react-router-dom` **HashRouter** (AD7). `#/` landing, `#/editor` editor. HashRouter chosen over BrowserRouter: zero 404 risk on GitHub Pages deep links; hash is invisible to the service worker (PWA-safe). |
| 2 | **Landing component** | New `LandingPage.tsx`, **not** a reworked `StartScreen`. StartScreen keeps its job (New/Open) as the editor's initial in-route state. |
| 3 | **Deployment** | GitHub Actions → GitHub Pages, auto on push to `main`. |
| 4 | **base path** | `command === 'build' ? '/behavior-tree-visualization-tool/' : '/'` so dev stays at `/`. PWA `start_url`/`scope` stay `'.'`. |
| 5 | **Search scope** | Active tree only (v1.11). Floating Ctrl+F bar (jsoncrack model). Highlight is a distinct visual, not the selection ring. |
| 6 | **Search state** | Transient store fields (`searchOpen`, `searchMatchIds`), excluded from `withSnapshot`/history (same pattern as `exportInProgress`). |
| 7 | **Templates storage** | Serialized v2-schema JSON strings in `src/templates/*.ts`, loaded through the existing `deserialize → setDocument` path (type-safe, bundled, base-proof — no `public/*.json` fetch). |
| 8 | **Dirty tracking** | Subscribe to `document` **reference** changes vs `lastSavedDocument` (no per-action flag setting). Covers non-`withSnapshot` mutations; no-op `return {}` keeps the reference so dirty isn't falsely set. |

## Out of Scope (v1.11)

- Cross-tree search; regex/JSONPath search.
- BrowserRouter / clean `#`-less URLs (would need a 404.html redirect hack on Pages).
- Command palette, right-click context menu (surveyed, deferred — user did not select).
- Autosave / localStorage document persistence (dirty guard is the v1.11 answer to data-loss risk).
- Custom domain.
