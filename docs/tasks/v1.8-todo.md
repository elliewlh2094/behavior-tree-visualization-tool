## T2 — Layout button uses `fitView` (FB1)

**Description:** In `src/hooks/useApplyLayout.ts`, replace the `setCenter(rootX, rootY) + getZoom()` calls with `fitView({ padding: 0.2, duration: 200 })`. `fitView` is already destructured from `useReactFlow()` in `Canvas.tsx:101` and used on tab switch — Layout adopts the same call.

**Acceptance criteria:**
- [ ] Layout on a multi-node tree centers and zooms so the bounding box of all nodes is visible with ~10% padding. (Spec AC4.1)
- [ ] Layout on a single-node tree centers without zooming above 1.0×. (Spec AC4.2)
- [ ] After Layout, the per-tab viewport store reflects the new viewport (already wired via `onViewportChange`). (Spec AC4.3)

**Risk:** memory `reference_xyflow_setcenter.md` flagged the zoom-snap gotcha for `setCenter`/`setViewport`; `fitView` has different semantics (computes target zoom from bounds), so the gotcha does not apply. Verify at the manual-smoke stage with both small (3-node) and large (15-node) fixtures.

**Verification:**
- [ ] `npm run typecheck` green.
- [ ] Manual smoke (`npm run dev`): open `e2e/fixtures/multi-tree-with-subtree.json`, scatter Layout on each tab; each tab framed with comfortable padding.

## T7 — BTNode label wrap + per-node layout heights (FB5)

**Description:** Let long node names wrap onto a second line and grow the node by one grid row (25 px). Keep default 75 px height for names that fit on one line. Truncate only when the name overflows two lines. Touches three files: `BTNode.tsx` for the label CSS + dropping the fixed `height` style, `tree-layout.ts` for an optional per-node-heights map in `LayoutOptions`, and `useApplyLayout.ts` to feed xyflow's existing `measured.height` through to the layout call.

**Acceptance criteria:**
- [ ] `BTNode.tsx` label `<div>` no longer carries the `truncate` class; gains `line-clamp-2 break-words text-center`. (Spec AC7.3 truncation source)
- [ ] `BTNode.tsx` wrapper no longer sets a fixed `height: NODE_HEIGHT` inline style; height auto-sizes between 75 px (one line) and 100 px (two lines). `width: NODE_WIDTH` is preserved. (Spec AC7.1, AC7.2)
- [ ] `tree-layout.ts` `LayoutOptions` gains optional `nodeHeights?: Map<string, number>`. Per-row pitch becomes `max(nodeHeights.get(id) ?? nodeHeight, ...) + gapY`. (Spec AC7.6)
- [ ] When `nodeHeights` is absent, `computeTreeLayout` output is byte-identical to v1.7.1. Verified by an existing test re-run, not a snapshot.
- [ ] `useApplyLayout.ts` reads each xyflow node's `measured.height` (post-paint) into a `Map<string, number>` and passes it through to `computeTreeLayout`. (Spec AC7.7)
- [ ] Root centering in `useApplyLayout.ts` uses Root's `measured.height` when available; falls back to `NODE_HEIGHT` constant.
- [ ] No change to `src/store/bt-store.ts`, `operations.ts`, or the file format. Heights are runtime measurements only — never persisted.

**Risk:**
- xyflow's `node.measured.height` is populated after the first paint, so the very first Layout press on a freshly opened tree may use the default-height fallback for unmeasured nodes. Acceptable: the next press uses real measurements. Document this behavior if any user-visible jitter surfaces during manual smoke.
- `line-clamp-2` is a webkit-prefixed property; verify it works in the project's supported browsers (Chrome/Edge/Firefox/Safari — all currently support it). No fallback needed.

**Verification:**
- [ ] `npm run typecheck` green.
- [ ] `npm run dev`: create a node, rename to `"This is a very long behavior name"`, observe height grows by 25 px and both lines render; rename to `"Step"` → returns to 75 px.
- [ ] `npm run dev`: three siblings under one parent, one with a long name; press Layout; no row overlap; wrapped node's edges land cleanly on its handles.

**Dependencies:** None for the BTNode CSS change. `useApplyLayout.ts` is also touched by T2 (`fitView` swap) — sequence T2 first, then layer T7's `nodeHeights` plumbing on top, or land both in a single commit.

**Files:** `src/components/canvas/BTNode.tsx`, `src/core/layout/tree-layout.ts`, `src/hooks/useApplyLayout.ts`.

**Estimated scope:** S.
