### T5 — Validation rules R9, R10 ✅ Done (commit `fe4bbc7`)

**Description:** Add two new validation rules for SubTree nodes: R9 (treeRef must reference an existing tree in the document) and R10 (no circular subtree references).

  - Severity: error
  - Message: `SubTree node "${name}" references unknown tree "${treeRef}".`
- [x] R10: No circular subtree references — covers self-loops (T → T) and longer cycles (A → B → A, A → B → C → A)

- [x] R1–R8 parameter type changed from `BehaviorTree` → `BTTreeDef`; `validate()` iterates `document.trees` for R1–R8 then runs R9/R10 once at document scope

No call sites changed; per-tree isolation came for free with the helper rewrite.
- [x] New tree starts with empty history (lazy init) and default viewport (xyflow's `fitView` runs on first mount; unvisited tabs get fitView via the restore effect — see below)
- [x] `removeTreeStateFor(treeId)` action — wired but unused; T11's tree-delete will call it. Drops `undoStacks[treeId]`, `redoStacks[treeId]`, `viewportByTreeId[treeId]`.

**Deviations from plan:**
- **Modal vs in-place confirm:** the original plan implied an in-place "Yes/No" pattern (mirroring `SettingsPanel.ResetSection`). First implementation tried that, but a 140–180px tab is too narrow — "Delete?" truncated to "Del…" and crowded the tab name. Replaced with a centered modal dialog (`<div role="dialog">`).
- **Tab strip overflow:** tabs with `flex` and no `min-w-0` compressed when many tabs were open and pushed the `+` button off-screen. Fixed by wrapping tabs in `overflow-x-auto` with `flex-shrink-0` per tab, and pinning `+` outside the scroll region so it's always visible.
- **Operations.ts:** the plan listed `core/model/operations.ts` as a likely-touched file for "pure tree CRUD operations". `operations.ts` works on a single `Treeish` shape (`rootId`, `nodes`, `connections`); document-level CRUD (which mutates `BTDocument.trees`) doesn't fit that shape. Implemented inline in the store next to `renameTree`, matching T9's precedent. Extracted a small `dropTreeState` helper shared between `deleteTree` and `removeTreeStateFor`.
